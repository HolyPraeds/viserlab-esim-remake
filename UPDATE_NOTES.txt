  ЧТО ИЗМЕНИЛОСЬ:
═══════════════════════════════════════════════════════════════

✅ ПЕРЕКЛЮЧАТЕЛЬ В HEADER:
   • Теперь переключатель валюты EUR/GBP виден в шапке сайта на всех страницах
   • Выбранная валюта сохраняется в localStorage браузера
   • При переключении в header автоматически обновляются все переключатели на странице
   • Работает синхронизация между header и локальными переключателями

✅ КУРС GBP:
   • Установлен курс: 1 EUR = 0.87 GBP
   • Для установки курса выполнить: php set_current_currency_rate.php

═══════════════════════════════════════════════════════════════
  УСТАНОВКА:
═══════════════════════════════════════════════════════════════

1. Распаковать обновлённый архив поверх папки core/
2. Выполнить миграции (если ещё не выполнены):
   php artisan migrate

3. Установить курс GBP:
   cd core
   php set_current_currency_rate.php

4. Очистить кэши:
   php artisan config:clear
   php artisan view:clear
   php artisan cache:clear
