1. Проверить API в браузере:
   http://localhost/api/currency/rates
   
   Должен вернуться JSON:
   {
     "status": "success",
     "base_currency": "EUR",
     "rates": {
       "GBP": {"code": "GBP", "rate": 0.87},
       "USD": {"code": "USD", "rate": 1}
     }
   }

2. Проверить тестовую страницу:
   http://localhost/test_currency.html
   
   - Должны быть кнопки EUR/GBP
   - При клике цены должны меняться
   - Курс: 100 EUR = 87 GBP

3. Проверить на реальной странице планов:
   - Открыть страницу с планами
   - Переключить валюту в header
   - Цены должны обновиться
