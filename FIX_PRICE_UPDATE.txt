  ИСПРАВЛЕНИЕ: Цены не меняются при переключении валюты
═══════════════════════════════════════════════════════════════

❌ ПРОБЛЕМА:
   На проде планы есть, но цены не меняются при переключении валюты

✅ ЧТО ИСПРАВЛЕНО:
───────────────────────────────────────────────────────────────

1. Улучшена функция updateAllPrices() в region_plans.blade.php:
   - Теперь использует window.globalCurrency из header
   - Правильно обновляет все цены в списке планов
   - Корректно обновляет символ валюты

2. Улучшена функция updateAllPricesOnPage() в header.blade.php:
   - Сначала вызывает специфичную функцию страницы (updateAllPrices)
   - Правильно находит элементы с ценами
   - Обновляет цены во всех местах

3. Исправлен обработчик клика на переключатель валюты:
   - Добавлена синхронизация с header
   - Добавлена задержка для загрузки курсов валют
   - Правильно обновляет все цены после переключения

═══════════════════════════════════════════════════════════════
  ЧТО ПРОВЕРИТЬ НА ПРОДЕ:
═══════════════════════════════════════════════════════════════

1. Открыть консоль браузера (F12)
2. Переключить валюту в header (EUR/GBP)
3. Проверить, что:
   - Цены в списке планов обновились
   - Символ валюты изменился
   - Цена в боковой панели обновилась
   - В консоли нет ошибок JavaScript

4. Если цены не обновляются:
   - Проверить, что API /api/currency/rates работает
   - Проверить, что курсы валют загружаются (в консоли)
   - Проверить, что baseCurrency правильный (должен быть USD на проде)

═══════════════════════════════════════════════════════════════
  ВОЗМОЖНЫЕ ПРОБЛЕМЫ:
═══════════════════════════════════════════════════════════════

1. Курсы валют не загружаются:
   → Проверить API endpoint /api/currency/rates
   → Проверить, что в БД есть записи в таблице currencies с conversion_rate

2. baseCurrency не совпадает:
   → На проде baseCurrency = USD (из gs('cur_text'))
   → Проверить, что в header правильно устанавливается window.baseCurrency

3. JavaScript ошибки:
   → Открыть консоль браузера
   → Проверить на наличие ошибок при переключении валюты
