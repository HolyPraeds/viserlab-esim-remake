# Исправление политик на продакшн сервере

## Проблема
На странице регистрации не отображаются ссылки на политики из-за проблем с таблицей `frontends`.

## Решение

### 1. Загрузите файл на сервер
Скопируйте файл `fix_production_policies.php` в корневую папку Laravel на сервере.

### 2. Выполните скрипт
```bash
cd /path/to/your/laravel/project
php fix_production_policies.php
```

### 3. Очистите кеш
```bash
php artisan cache:clear
php artisan view:clear
php artisan config:clear
```

## Что делает скрипт

1. **Удаляет старые записи** политик из таблицы `frontends`
2. **Создает новые записи** с правильными заголовками:
   - Privacy Policy
   - Terms of Service  
   - Cookies Policy
3. **Добавляет полный контент** для каждой политики
4. **Проверяет результат** и выводит информацию

## Результат

После выполнения скрипта:
- ✅ Страница регистрации будет показывать ссылки на политики
- ✅ Страницы политик будут работать корректно
- ✅ Контент политик будет отображаться правильно

## Проверка

Проверьте эти страницы:
- `/user/register` - должны быть ссылки на политики
- `/policy/privacy-policy` - должна загружаться страница с контентом
- `/policy/terms-of-service` - должна загружаться страница с контентом  
- `/policy/cookies-policy` - должна загружаться страница с контентом

## Если что-то пошло не так

1. Проверьте подключение к базе данных
2. Убедитесь, что таблица `frontends` существует
3. Проверьте права доступа к файлам
4. Очистите кеш браузера
