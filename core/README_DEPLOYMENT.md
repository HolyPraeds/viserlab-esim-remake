# Развертывание на продакшн сервере

## Что нужно сделать на сервере:

### 1. Загрузить обновленные файлы
Убедитесь, что на сервере есть все обновленные файлы:
- `core/resources/views/templates/basic/country_plans.blade.php`
- `core/resources/views/templates/basic/region_plans.blade.php`
- `core/app/Http/Controllers/SiteController.php`
- `core/app/Models/Plan.php`
- `core/app/Http/Helpers/helpers.php`

### 2. Запустить скрипт развертывания
Выполните на сервере:
```bash
cd /path/to/your/laravel/project/core
php deploy_to_production.php
```

### 3. Альтернативно - запустить отдельные скрипты
Если нужно исправить только цены:
```bash
php fix_production_server.php
```

Если нужно исправить только политики:
```bash
php fix_production_policies.php
```

## Что делает скрипт:

### Исправление валюты:
- ✅ Устанавливает EUR как базовую валюту
- ✅ Настраивает курсы конвертации (1 EUR = 1.085 USD)
- ✅ Конвертирует ВСЕ планы из USD в EUR в базе данных
- ✅ Очищает все кеши Laravel

### Исправление политик:
- ✅ Удаляет старые записи политик из таблицы `frontends`
- ✅ Создает новые записи с правильными заголовками и контентом
- ✅ Исправляет ссылки на политики на странице регистрации

## После запуска скрипта:

1. **Проверьте главную страницу** - цены должны быть в EUR
2. **Проверьте страницы стран** - все тарифы в EUR
3. **Проверьте страницы регионов** - все тарифы в EUR
4. **Проверьте страницу регистрации** - должны быть ссылки на политики
5. **Проверьте страницы политик** - должен отображаться правильный контент

## Если что-то не работает:

1. **Очистите кеш браузера** (Ctrl+F5)
2. **Проверьте права доступа** к файлам
3. **Убедитесь, что PHP может выполнять shell_exec()** для очистки кешей
4. **Проверьте логи Laravel** в `storage/logs/laravel.log`

## Примеры результатов:

### До исправления:
- Burkina Faso 1GB: $142.00 USD
- Burkina Faso 3GB: $352.00 USD
- Burkina Faso 5GB: $520.00 USD

### После исправления:
- Burkina Faso 1GB: €130.88 EUR
- Burkina Faso 3GB: €324.42 EUR
- Burkina Faso 5GB: €479.26 EUR

## Безопасность:

Скрипт безопасен для продакшн сервера:
- ✅ Не удаляет данные пользователей
- ✅ Только обновляет настройки и планы
- ✅ Создает резервные копии через Laravel
- ✅ Очищает кеши для применения изменений
