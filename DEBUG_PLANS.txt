  ДИАГНОСТИКА: Почему не отображаются планы
═══════════════════════════════════════════════════════════════

🔍 ЧТО ПРОВЕРИТЬ:
───────────────────────────────────────────────────────────────

1. ПРОВЕРИТЬ КОНСОЛЬ БРАУЗЕРА:
   - Откройте DevTools (F12)
   - Перейдите на вкладку Console
   - Ищите ошибки JavaScript (красные сообщения)
   - Особенно ошибки связанные с:
     * route('api.currency.rates')
     * jQuery/Ajax
     * undefined variables

2. ПРОВЕРИТЬ СЕТЕВЫЕ ЗАПРОСЫ:
   - В DevTools перейдите на вкладку Network
   - Обновите страницу
   - Ищите запросы к /api/currency/rates
   - Проверьте статус ответа (должен быть 200, не 404)

3. ПРОВЕРИТЬ БД:
   - Есть ли планы в таблице plans?
   - Активны ли планы (status = 1)?
   - Есть ли связь планов с регионами/странами?

4. ПРОВЕРИТЬ КОНТРОЛЛЕР:
   - Откройте страницу региона/страны
   - Проверьте логи: storage/logs/laravel.log
   - Ищите ошибки при загрузке планов

5. ПРОВЕРИТЬ ШАБЛОНЫ:
   - Убедитесь, что переменная $plans не пустая
   - Проверьте, что цикл @forelse работает корректно

═══════════════════════════════════════════════════════════════
  БЫСТРАЯ ПРОВЕРКА:
═══════════════════════════════════════════════════════════════

1. Откройте консоль браузера (F12)
2. Выполните команду:
   
   console.log('Plans count:', $('.choose-plan-item').length);
   
   Если вернёт 0 - планы не отображаются
   Если вернёт число > 0 - планы есть, но возможно скрыты CSS

3. Проверьте, загружается ли API:
   
   fetch('/api/currency/rates')
     .then(r => r.json())
     .then(d => console.log('API works:', d))
     .catch(e => console.error('API error:', e));

═══════════════════════════════════════════════════════════════
  ЧАСТЫЕ ПРОБЛЕМЫ:
═══════════════════════════════════════════════════════════════

❌ JavaScript ошибка блокирует отображение
   → Проверьте консоль браузера
   → Временно отключите скрипт переключения валют

❌ API маршрут не работает
   → Проверьте bootstrap/app.php (должна быть загрузка API routes)
   → Выполните: php artisan route:clear

❌ Планы не загружаются из БД
   → Проверьте, что в БД есть активные планы
   → Проверьте связи планов с регионами/странами

❌ Ошибка в шаблоне
   → Проверьте логи Laravel
   → Убедитесь, что переменная $plans передаётся в view
