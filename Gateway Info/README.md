# Gateway Integration Docs

Этот каталог содержит актуальную документацию по платёжной интеграции в проекте `viserlab-esim-remake`.

## Структура

- `ALPPay_Integration.md` – основная схема интеграции AlpPay:
  - депозиты (user wallet top‑up)
  - оплата eSIM заказов (checkout)
  - вебхуки и статусы
  - необходимые `.env` переменные

## Как использовать

- Для онбординга нового мерчанта по AlpPay:
  1. Прочитать `ALPPay_Integration.md` (разделы **Конфигурация** и **Потоки**).
  2. Настроить переменные окружения `.env` согласно разделу **.env / config**.
  3. Убедиться, что `ALPPAY_WEBHOOK_URL` доступен из интернета и указывается в кабинете AlpPay.
  4. Прогнать тесты по чек‑листу из раздела **Тестирование и отладка**.
