═══════════════════════════════════════════════════════════════
  ШАГИ УСТАНОВКИ:
═══════════════════════════════════════════════════════════════

1️⃣ РАСПАКОВКА ФАЙЛОВ
───────────────────────────────────────────────────────────────
   Распаковать содержимое архива ПОВЕРХ существующей папки `core/`
   (с сохранением структуры каталогов).

2️⃣ ВЫПОЛНЕНИЕ МИГРАЦИЙ БД
───────────────────────────────────────────────────────────────
   В папке `core/` выполнить:
   
   php artisan migrate

   Это добавит поле `payment_currency` в таблицу `orders`.

3️⃣ ОЧИСТКА КЭШЕЙ LARAVEL
───────────────────────────────────────────────────────────────
   В папке `core/` выполнить:
   
   php artisan route:clear
   php artisan config:clear
   php artisan view:clear
   php artisan cache:clear
   
   ⚠️ ВАЖНО: Обязательно выполнить `php artisan route:clear` для очистки 
   кэша маршрутов, иначе новый API endpoint не будет работать!

4️⃣ ПРОВЕРКА КУРСОВ ВАЛЮТ В БД
───────────────────────────────────────────────────────────────
   Убедиться, что в таблице `currencies` есть записи:
   
   - api_currency = 'EUR' с conversion_rate (курс от базовой валюты)
   - api_currency = 'GBP' с conversion_rate (курс от базовой валюты)
   
   Например:
   - Если базовая валюта EUR, то для GBP может быть conversion_rate = 0.85
     (означает: 1 EUR = 0.85 GBP)
   - Если базовая валюта USD, то для EUR может быть conversion_rate = 0.92
     (означает: 1 USD = 0.92 EUR)

   ⚠️ Если курсов нет, можно добавить через админку или напрямую в БД.

5️⃣ ПРОВЕРКА ПЛАТЁЖНОГО ПРОВАЙДЕРА
───────────────────────────────────────────────────────────────
   Убедиться, что AlpPay/Taurixy поддерживает валюты EUR и GBP.

═══════════════════════════════════════════════════════════════
  ЧТО ДОЛЖНО РАБОТАТЬ ПОСЛЕ УСТАНОВКИ:
═══════════════════════════════════════════════════════════════

✅ НА ВИТРИНЕ:
   • На страницах выбора планов (регионы/страны) есть переключатель EUR/GBP
   • При переключении валюты цены автоматически конвертируются по курсу из БД
   • На страницах Coverage и Destination также есть переключатель валюты

✅ ПРИ ОФОРМЛЕНИИ ЗАКАЗА:
   • Выбранная валюта (EUR/GBP) сохраняется в заказе
   • Цена плана конвертируется в выбранную валюту при создании заказа
   • Платёж реально уходит в выбранной валюте (EUR или GBP)

✅ API:
   • Доступен endpoint: GET /api/currency/rates
   • Возвращает курсы валют для конвертации на фронте

═══════════════════════════════════════════════════════════════
  ТЕХНИЧЕСКИЕ ДЕТАЛИ:
═══════════════════════════════════════════════════════════════

• Конвертация происходит через helper-функцию convertCurrency()
• Курсы валют загружаются через API endpoint /api/currency/rates
• На фронте используется JavaScript для пересчёта цен при переключении
• При создании заказа цена конвертируется на бэкенде в выбранную валюту

═══════════════════════════════════════════════════════════════
  ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ:
═══════════════════════════════════════════════════════════════

❌ Переключатель не работает / цены не конвертируются:
   → Проверить, что курсы валют есть в таблице `currencies`
   → Проверить консоль браузера на ошибки JavaScript
   → Убедиться, что API endpoint /api/currency/rates доступен

❌ Платёж не проходит в выбранной валюте:
   → Проверить, что платёжный провайдер поддерживает EUR и GBP
   → Проверить логи Laravel на ошибки при создании заказа

❌ Ошибка миграции:
   → Проверить, что таблица `orders` существует
   → Проверить, что поле `payment_currency` ещё не добавлено
